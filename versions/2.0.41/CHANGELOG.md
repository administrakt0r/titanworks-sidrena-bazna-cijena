# Titanworks Bazna Cijena 2.0.41

* New: "Cart and checkout" display setting. The reference lines in the cart, mini-cart and checkout are now off by default and can be enabled in Display settings.
* Change: when enabled, cart and checkout lines use the label configured in settings (including date tokens) instead of a fixed "Bazna cijena".
* Upgrade note: existing installs no longer show cart and checkout reference lines until the setting is enabled.
